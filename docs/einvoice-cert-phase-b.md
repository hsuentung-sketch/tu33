## 開完 18 張後的驗證步驟

### 1. 立即檢查（開票當下）
每張開完應該：
- ✓ 潤樋後台發票列表出現該筆，status = issued
- ✓ 有 PDF / F0401 XML / (作廢/註銷/折讓對應) XML 連結
- ✓ 儀表板「近 7 天狀態」issued 數字增加

### 2. Turnkey 送出（15-30 分鐘後）
LISH 貼：
```bash
find /opt/turnkey/app/linux/EINVTurnkey/SendFile/B2SSTORAGE/BAK/ -name "*JZ50075*" -newer /tmp/marker 2>/dev/null | wc -l
```

### 3. EINV 對帳（1-24 小時後）
每張到 https://wwwtest.einvoice.nat.gov.tw：
- 營業人功能選單 → **銷項發票查詢**
- 期別 `115/07-08` + 各張號碼查詢
- 截圖存 `docs/einvoice-cert-evidence/phase-b/B0X-einv-confirm.png`

### 4. XML 佐證
每張的 F0401（+ 有的話 F0501/F0701/G0401/G0501）XML 下載存證：
- 潤樋後台 → 發票列表 → 該張 → 點 XML 連結 → 存檔到 `docs/einvoice-cert-evidence/phase-b/xml/`
