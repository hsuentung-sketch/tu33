優勢分析 (Strengths)

1️⃣ 行業專屬代碼 🔴 核心競爭力

為貿易、環保、製造、物流各行業客製系統，不是套版改改

  • 貿易案例: 報價 30-60分 → 3分 (降 95%), 催收 -70%
  • 環保案例: 派車1小時 → 10分, AI 駕駛報告自動化
  • 製造案例: 14台CNC即時監控, 13階段製程, FOCAS 5秒更新

對手 18 個月無法複製

2️⃣ LINE 原生操作介面 🟢 永久差異化

員工用 LINE 完成整個工作流，符合台灣工廠文化

  • 員工無需學習新系統（已用 LINE）
  • 推播通知、待辦、簽核、查詢全在 LINE
  • FansySoft: 需要學習後台系統 + 手機 APP

3️⃣ CNC 機台直接整合 🟢 3-6個月優勢

FANUC FOCAS 內建，對手需外掛 MES

  • 5秒即時監控
  • 自動派工推薦
  • AI 圖面辨識

4️⃣ 定價透明度 🟢 永久優勢

維度 潤樋 FansySoft
月租 NT$10-30K (全包) NT$50-300K (推測)
包含內容 8 項服務 分項計費
整合費 月租內含 另計
AI 模組 內建 ($0.005/次) 另購

項目 潘樋 FansySoft 年度差異
月租 NT$15K NT$80K -NT$780K
首次建置 NT$15K NT$300K+ -NT$285K
總年度 NT$195K NT$575K+ 節省 65%

劣勢分析 (Weaknesses)

1️⃣ 品牌知名度 🔴 巨大差距

維度 潘樋 FansySoft
成立時間 新公司 深耕 10+ 年
市場客戶 ~50 家 150+ 家
認知度 低 Liferay 企業級背書
大客戶案例 無 政府、金融、製造

2️⃣ 銷售通路薄弱 🔴 直接威脅

  • 主要靠直銷，經銷商/代理合作少
  • 無 CNC 廠商推薦渠道
  • 客戶難以找到我們，FansySoft 更容易被推介

3️⃣ 研發資源限制 🟡 中等風險

小團隊，一次只能做一個行業。客製化多 → 標準化難

4️⃣ 技術棧小眾 🟡 長期隱患

TypeScript + Node.js + Prisma → 台灣開發人員少

對比 FansySoft: Liferay + Java EE → 龐大開發社群

機會分析 (Opportunities)

1️⃣ 製造業數位化浪潮 🔥 巨大市場

  • 台灣製造業 SMB 約 1-2 萬家
  • 年營收 NT$50M-500M 的廠房約 5000 家
  • 其中僅 30% 有 ERP 系統
  • 未滲透市場: 3500 家廠房

市場規模估算:

  • 目標市場: 3500 家廠房
  • 可達成: 300-500 家 (佔有率 10-15%)
  • 年收入: 300 × NT$15K × 12 = NT$54M (保守)

2️⃣ CNC 經銷商合作生態 🟡 可開發

  • FANUC、台灣大廠 (牧野、森精機) 經銷商
  • 銷售 CNC 時推薦 ERP → "買機台送 ERP" 概念
  • 合作成本低 (純推薦，無分潤)

預期效果: 每個經銷商 1年可推介 20-50 個客戶

15 家經銷商 = 300-750 個新客戶/年

3️⃣ 快速落地為行銷優勢 🟢 可直接轉化

  • 貿易: "報價 3分搞定" ← 很吸引中小廠
  • 環保: "派車效率 +600%" ← 運費直接下降
  • 製造: "CNC 實時掌握" ← 現成的痛點

4️⃣ AI 功能內建優勢 🟢 新需求

  • 語音下單、OCR、績效報告已上線
  • 成本低 ($0.005/次)
  • 比 FansySoft 早 6-12 個月主推

威脅分析 (Threats)

🔴 FansySoft 市場滲透

威脅等級: 高

時間軸: 3-6 個月內

潛在行動:

  • 推出中小企業版本 (NT$20-30K)
  • 簡化上線流程
  • 走地盤式銷售

衝擊: 定價優勢消失，認知度落差擴大

🟡 其他本地 ERP 廠商

威脅等級: 中

對手: DSC、各類進銷存系統

特點:

  • 專門針對特定行業
  • 定價可能更低
  • 但功能不完整

🟡 低代碼平台興起

威脅等級: 低-中 (3-5年)

平台: Microsoft Power Apps、Bubble

風險: 降低客製開發需求

🔴 資金與規模劣勢

威脅等級: 高 (長期)

潘樋面臨: 無融資，靠自營養

FansySoft 優勢:

  • 可能被 PE 注資
  • 大規模併購其他廠
  • 快速擴張市場份額

🟡 人才流失與薪資競爭

威脅等級: 中 (持續風險)

風險: 小公司無法與大廠競爭薪資

衝擊: 若關鍵開發者離職，客支中斷

專家建議 (優先順序)

🔴 P1 - 立即執行 (本月內完成) — 防守 + 搶佔市場

P1.1

成本計算機 + ROI 展示工具

成本: NT$50-80K 週期: 2-3 週 效果: 決策興趣 +300%

內容: 互動式 Web 工具，輸入員工數→自動算成本差異

範例: 30人廠房月100張訂單

  • 潘樋: NT$180K/年 (月 15K)
  • FansySoft: NT$720K+/年 (月 60K)
  • 手工成本: NT$1.2M/年
  • 節省: NT$1.02M/年 (85%)
P1.2

行業案例深度化 (PDF Case Study)

成本: NT$30-50K 週期: 3-4 週 轉換率: +150%

三個獨立版本:

  • 貿易: 報價效率 (30分 → 3分), 催收自動化
  • 環保: 派車調度 (1小時 → 10分), EPA 合規
  • 製造: CNC 監控, 製程追蹤, 派工推薦

各自 10-15 頁，包含客戶背景、導入過程、ROI 計算

P1.3

短視頻行銷 (60秒示範)

成本: NT$80-120K 週期: 2-3 週 效果: 流量 +200-300%

三個版本: 報價、派車、CNC 監控

發行: YouTube、LinkedIn、官網、廣告投放

🟠 P2 - 本週末完成 (2-3 週) — 打開通路 + 增加認知

P2.1

CNC 經銷商合作方案 🟢 最高期望

成本: 低 週期: 2-3 週 新客戶: 60-250 個/年

目標經銷商: FANUC (~30家), 牧野 (~10家), 森精機 (~10家)

推薦方案:

  • 首年免費使用 (賓至如歸)
  • 銷售支持物料 (簡報、demo、ROI計算)
  • 技術支持 SLA (48小時響應)

預期結果: 3-5 家經銷商簽署 (3個月內)

P2.2

官網改版 + SEO 優化

成本: NT$100-150K 週期: 2-3 週 目標: 搜索前 3

改版方向:

  • 首頁故事化 (月省 NT$100K的主題)
  • 客戶推薦 (信任度)
  • 產業分頁 (貿易、製造、物流)
  • 內容營銷 (每週部落格)

SEO 目標: 搜索 "廠房 ERP" → 前 3

P2.3

工業協會合作

成本: 低 週期: 1-2 週 新客戶: 50-200 個

合作對象: 機械業者、貿易商、環保清運協會

內容輸出: 免費講座、會員優惠、官網推薦

🟡 P3 - 本月底完成 (3-4 週) — 防守核心競爭力

P3.1

防守 FansySoft 中小企業版風險

結論與最終建議
